# Keybinds

Defined in `dotfiles/config/hypr/hyprland.conf`.

## Applications

| Keys | Action |
| --- | --- |
| `ALT + SPACE` | App launcher (rofi) |
| `ALT + T` | Terminal (kitty) |
| `ALT + D` | Discord (Equibop) |
| `ALT + F` | Zen browser |
| `ALT + M` | Music (cmus) |
| `ALT + C` | Cutter (AppImage) |
| `ALT + SHIFT + 0` | Session (AppImage) |
| `ALT + S` | Theme & settings menu |
| `SUPER + E` | Files (Nautilus) |
| `SUPER + S` | GNOME settings |
| `SUPER + W` | Ranger (in kitty) |

## Workspaces

Ten global workspaces: `ALT + 1..9` and `ALT + 0` for workspace 10.

| Keys | Action |
| --- | --- |
| `ALT + {1-9,0}` | Switch to workspace |
| `SUPER + {1-9,0}` | Move window to workspace |
| `CTRL + ALT + ←/→` | Previous / next workspace |

## Windows

| Keys | Action |
| --- | --- |
| `SUPER + arrows` | Focus window |
| `SUPER + SHIFT + arrows` | Move window |
| `SUPER + CTRL + arrows` | Resize window |
| `SUPER + ALT + arrows` | Resize window (opposite edge) |
| `ALT + SHIFT + arrows` | Move floating window |
| `SUPER + T` | Toggle floating |
| `SUPER + P` | Pseudo-tile |
| `SUPER + V` | Toggle split |
| `SUPER + F` / `SUPER + SHIFT + F` | Fullscreen / real fullscreen |
| `ALT + Z` | Close window |
| `SUPER + CTRL + {1-9}` | Set split ratio 0.1-0.9 |
| `SUPER + LMB drag` | Move window |
| `SUPER + RMB drag` | Resize window |

## System

| Keys | Action |
| --- | --- |
| `SUPER + SUPER_L` | Toggle control center |
| `SUPER + L` | Lock screen |
| `SUPER + ESCAPE` | Power menu |
| `SUPER + \`` | Clipboard history |
| `PRINT` | Screenshot to clipboard |
| `SUPER + SHIFT + S` | Region screenshot |
| `SUPER + SHIFT + R` | Save screenshot |
| `SUPER + ALT + R` | Reload Hyprland |
| `SUPER + ALT + Q` | Exit Hyprland session |

## Media & hardware

| Keys | Action |
| --- | --- |
| `XF86AudioRaiseVolume` / `LowerVolume` | Volume ±5% |
| `XF86AudioMute` | Mute output |
| `XF86AudioMicMute` | Mute microphone |
| `XF86AudioPlay` / `Next` / `Prev` | Media control |
| `XF86MonBrightnessUp` / `Down` | Brightness ±5% |
