# Getting started

## Requirements

- An existing NixOS install (the installer creates the host config for you).
- A user with `sudo` access.
- Network access to fetch the flake inputs the first time.

## Install

Download the archive from the repository (or a release) and extract it:

```bash
unzip pwnbox.zip     # or: tar -xzf pwnbox.tar.gz
cd pwnbox
```

Then run the installer from the flake directory:

```bash
./scripts/install.sh switch
```

Running `./scripts/install.sh` without arguments shows the help screen with a
prompt for the default action; `./scripts/install.sh --help` prints the same
screen. The installer:

1. Detects your user, host name, time zone and hardware.
2. Creates `hosts/<host>/` from the `nixos` template if it does not exist
   (the template's monitor pins are cleared, so the new machine starts with
   automatic display arrangement — pin `mainMonitor` / `leftMonitor` in the
   host file afterwards if you want a fixed layout).
3. Refreshes the machine-specific files for the current machine on every run:
   `hardware-configuration.nix` (always regenerated from
   `/etc/nixos/hardware-configuration.nix` or `nixos-generate-config`) and
   `boot.nix` (regenerated only when it carries the
   `auto-generated by install.sh` marker, so hand-written loader setups are
   left alone).
4. Runs `nixos-rebuild` with the flake. Garbage collection is opt-in with
   `--gc`; by default old generations are kept so you can roll back.

The run starts with a preflight inspection and then reports each execution
phase in a compact table.

### Installer actions

| Action | What it does |
| --- | --- |
| `switch` | Build and activate, persistent (default) |
| `test` | Build and activate for this boot only |
| `boot` | Build and set as the default for the next boot |
| `build` | Build only, do not activate |
| `dry-activate` | Build and show what would change, do not activate |

### Installer options

| Option | Meaning |
| --- | --- |
| `-H`, `--host HOST` | Flake host to build (default: short hostname) |
| `-g`, `--gc` | Collect garbage before rebuilding (deletes old generations) |
| `-n`, `--no-gc` | Keep old generations (default) |
| `-v`, `--verbose` | Stream all output (default is quiet) |
| `-- EXTRA...` | Extra arguments passed to `nixos-rebuild` |

Examples:

```bash
./scripts/install.sh build
./scripts/install.sh test -H myhost
./scripts/install.sh switch --verbose
./scripts/install.sh switch -- --show-trace
```

## After install

Useful commands:

| Command | Does |
| --- | --- |
| `./scripts/install.sh switch` | Rebuild and activate |
| `update` | Update all flake inputs, then rebuild (shell alias) |
| `ALT + S` | Open the theme / settings menu |

## Host configuration

The generated `hosts/<host>/default.nix` is the single place to tune the
machine. Common options:

```nix
pwnbox = {
  hostName = "myhost";
  timeZone = "Europe/Berlin";
  username = "pwnbox";

  desktop = {
    enable = true;
    resolution = "2560x1440@144";
    accessibility = false;
  };

  vpn.mullvad = false;

  virtualisation = {
    docker = true;
    dockerOnBoot = false;
    libvirtd = true;
    wireshark = true;
  };

  packages = {
    hacking = true;
    gaming = false;
    creative = false;
  };
};
```

Every option is documented in `modules/nixos/options.nix`.

`hardware-configuration.nix` and the auto-generated `boot.nix` belong to the
machine and are refreshed by `scripts/install.sh` on every run — put kernel
modules, loader tweaks or anything else you want to keep in `default.nix`
instead.

## Wallpapers

Wallpapers live in the flake at `dotfiles/gnome/wallpapers/` and are linked
read-only to `~/.local/share/pwnbox/wallpapers`. Add an image there and rebuild,
then pick it from `ALT + S → Pywal`.

## IDA Free / Pro

IDA is proprietary and is **not** installed by the flake. Install it
yourself (any directory); with `packages.hacking` on, the flake provides
the FHS wrapper (`ida`, `ida64`, `idat`, `hv`), launcher entries, the pywal
theme, fonts and a pseudocode plugin — see
[Apps](../usage/apps.md#ida-free--pro).

```bash
# default install location
~/Software/RE/IDA

# use another location
PWNBOX_IDA_HOME=/opt/ida-9.4 ida
```

## Stremio Enhanced

Stremio Enhanced ships preinstalled. On first boot the streaming server is
seeded automatically, and the pwnbox theme is generated into
`~/.config/stremio-enhanced/themes/`. Open Stremio Enhanced, go to
Settings → Themes and apply the **pwnbox** theme once; from then on it
follows every wallpaper / custom theme switch (restart the app after
switching). See [Apps](../usage/apps.md#stremio-enhanced).

## Recovery

If a build breaks the system, boot an older generation from the boot menu and
rebuild. You can also activate a previous configuration with:

```bash
sudo /nix/var/nix/profiles/system-<n>-link/bin/switch-to-configuration switch
```

The installer writes its full log to `/tmp/pwnbox-install.log`.
