# Code of conduct

## The short version

Be respectful. No harassment, no bigotry, no spamming. Security research and
offensive tooling are the point of this project; using them against people
who did not consent is not.

## The long version

This project adopts the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The full text applies as written; the summary above is not a
substitute for it.

## Enforcement

Report violations privately to
[kern@skuntir.com](mailto:kern@skuntir.com). Reports are treated
confidentially. Repeated or severe violations result in removal from the
project (issue locks, PR rejection, blocking) at the maintainer's
discretion.
